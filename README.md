Pada modul ini dilakukan pengembangan halaman profil mahasiswa dengan beberapa fitur:

3. Tombol verifikasi status mahasiswa menggunakan SnackBar.
4. Pengujian Hot Reload (r) dan Hot Restart (R).

Pada modul ini dilakukan pengembangan Dashboard Akademik Mahasiswa TRPL dengan fitur:

6. Light Mode dan Dark Mode dengan tombol pengaturan tema.
